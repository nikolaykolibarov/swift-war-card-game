# War Card Game

A classic War card game built for iOS. Two players compete by drawing cards, and the player with the higher card wins the round. The game tracks scores and continues until players decide to stop.

## Tech Stack

| Technology | Description |
|------------|-------------|
| Swift | Programming language |
| UIKit | UI framework |
| Xcode | IDE |
| iOS | Target platform |

## Features

- Two-player card game
- Random card generation using 13 different cards (Ace through King)
- Real-time score tracking for both players
- Visual card display with image assets
- Simple tap-to-deal gameplay

## Prerequisites

- macOS with Xcode 8.0 or later
- iOS 10.0+ deployment target
- iOS Simulator or physical iOS device

## How to Build and Run

1. Clone the repository:
   ```bash
   git clone https://github.com/nikolaykolibarov/swift-war-card-game.git
   ```

2. Open the project in Xcode:
   ```bash
   cd swift-war-card-game
   open War.xcodeproj
   ```

3. Select a simulator or connected device

4. Press `Cmd + R` to build and run
